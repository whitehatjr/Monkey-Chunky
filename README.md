# Monkey Chunky App: React Native Phonics App -2020

> ⚠️ Note: This is a very old React Native project, built early in your learning journey.
> It may require updating dependencies or React Native versions to run on modern setups.

This app is designed to help users learn phonics by breaking words into smaller chunks and playing their corresponding sounds.

# Features

Word Input: Users type a word in the input box.

Chunk Display: The app splits the word into chunks stored in a local database.

Phonic Sound Buttons: Each chunk has a button that plays its phonetic sound.

Error Handling: Alerts the user if the word is not in the database.
